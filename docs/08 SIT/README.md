## Choices worth knowing

- **One criterion is one AcceptanceCriteria cell.** `BIBLE_COLUMN_DICTIONARY.md` defines the cell as
  the criterion and its `; `-separated parts as clauses inside it. One case per clause would have
  made the 1:1 mapping depend on how a splitter reads punctuation. `CriterionRef` is `<story>/AC`,
  and clauses are numbered `C1..Cn` inside `ExpectedResult`.
- **The default clock is `T0 = 2026-08-14T12:50:00Z`**, a Friday (18:20 Asia/Kolkata), because
  `S-RPT-11` pins exactly that instant. When a cell pins its own instant, its case uses that instant
  instead. No case reads the wall clock.
- **The precondition is data.** Each case lists the fixture id, plus every id, instant, price,
  reference and named constant the cell states literally. When a cell asserts a property of *any*
  row, the case binds that row to the lowest matching id in `FX-20-SEED` and says so.
- **The zero-double-booking case is `SIT-XCT-01`.** It runs
  `scripts/stress_seats.py --showtime 41 --seat 312 --n 50`, expects **exactly 1 HTTP 201 and exactly
  49 HTTP 409 `SEAT_UNAVAILABLE`**, and then expects `booking_seat` to hold one row for `(41, 312)`.
  `SIT-SEA-18` is the same proof at `(77, 402)`. The red-proof of the dropped constraint is
  P-XCT-01 Stage B, and per `GOAL_10` it is out of scope here: it is a negative case and belongs to
  `GOAL_11`.
