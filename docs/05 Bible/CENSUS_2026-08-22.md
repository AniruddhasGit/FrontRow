# Bible census — every acceptance criterion graded, 2026-08-22

```
Method ........... ten fresh zero-context readers, twenty cells each, disjoint,
                   covering all 200 stories. Each graded OK / VAGUE / WRONG and
                   was required to QUOTE the defeating clause and say either why
                   a correct implementation fails it or why a broken one passes.
Why a census ..... three sampled rounds of twenty scored 10/20, 12/20 and 8/20
                   and were not converging. Sampling repaired cells nobody had
                   read and left 180 unexamined.
```

## The 91 are not 91 mistakes. They are eight, repeated.

### 1. A search that matches the test running it — about 20 cells
A criterion asserts `rg '<pattern>' backend/` returns 0 hits. The test that issues that command
lives in `backend/tests/` and carries the pattern as a literal argument, so the search matches its
own source. **The rot is one tree deeper than it looks**: several cells carefully exclude `docs/`
*for exactly this reason* and then leave `backend/` in scope.

`S-XCT-09` is the clearest: it sweeps for `DELETE FROM (…|users|…)` while **the same cell mandates a
test containing `DELETE FROM users`**.

### 2. A per-request value asserted as a literal — about 8 cells
`a1b2c3d4` is the specification's *illustration* of a request id. The envelope generates a fresh one
per request and never trusts an inbound `X-Request-Id`. Cells assert it verbatim in 500 messages, on
audit rows, and in log filters. `S-XCT-22` shows the correct form — derive it from the response.

### 3. A bound that absence also satisfies — about 6 cells
`TTL … at or below 180`. Redis returns `-2` for a missing key and `-1` for a key with no expiry, and
both are "at or below". **A build that never creates the key passes the test for creating it.**
`S-XCT-36` uses the bound correctly one clause earlier in the same cell.

### 4. A system view that cannot answer the question — about 5 cells
`information_schema.referential_constraints` carries constraint names and rules and **no table or
column**, so no query over it decides *which* foreign key exists.
`pg_stat_xact_user_tables` reports only the **calling** transaction, so the application's writes are
invisible and the sum is `0` however broken the code is.

### 5. A catalog query with no schema filter — about 4 cells
`information_schema.columns WHERE column_name = 'version'` also returns PostgreSQL's own
`pg_available_extension_versions.version`. `WHERE column_name ~ '(total)'` also returns
`pg_stat_progress_copy.bytes_total`. **A correct schema fails on day one.** `S-XCT-09` writes the
same query correctly with `table_schema = 'public'`.

### 6. Equality over something that varies — about 8 cells
`PTTL unchanged` compares a millisecond countdown across an HTTP request. A presigned URL carries a
signature and a timestamp. Two error bodies carry two request ids. `S-SEA-17` states the same check
correctly, with a tolerance.

### 7. A framework misunderstanding — about 5 cells
`include_router()` **flattens** routers into the application, so `app.routes` holds `APIRoute`
objects and never an `APIRouter` — a correct four-router build yields **zero**.
`before_cursor_execute` receives **parameterised** SQL, so a literal `IN (2, 5)` never appears.
An unescaped `(` in `add_job(` makes ripgrep **abort**, so the anti-scheduler sweep never runs at
all and a codebase full of schedulers passes.

### 8. Arithmetic, calendars and counts — about 5 cells
**15 August 2026 is a Saturday**, asserted as `'Fri 15 Aug'` — and the neighbouring cell gets the
same calendar right. An enumeration of eleven lookup rows called "twelve". A minimum scroll of 21 px
asserted as 28. `WHERE movie_id <> <one value>` asserted to return 0 over a table holding eight.

## Defects the Bible inherited rather than caused

These are **PRD** defects. Fixing the Bible against them would fix the wrong document.

- **`Retry-After` is defined twice, incompatibly.** `E5` states `ceil(window_seconds / capacity)`
  and separately works an example giving `60` at `t=30s`; `ceil(900/10)` is `90` at every instant.
- **"Twelve cross-field checks" in prose; thirteen in the table.** A criterion copied the twelve —
  and an engineer who makes that test pass **ships twelve checks and drops the mail-transport one**,
  after which receipts fail silently.
- **A customer-facing message that the product falsifies.** The Redis-outage sentence says *"You can
  still look at showtimes and seat maps."* while the seat map returns **503 in that same outage**.
  Both tests pass and the sentence is untrue.
- **`S-BRW-01` pins an open reserved question in a test.** It states it does not answer
  `OPEN-BRWVIS-01` and then asserts the outcomes that answer it — and the contract backs that
  reading.

## Defects this session's own repairs caused

Recorded because the honesty floor requires it, and because they are the argument for fixing by
class rather than by cell.

- **`S-XCT-23` was invalidated by a PRD fix.** It asserts `METHOD_NOT_ALLOWED` is absent from the
  contract *"until the merge owner adds it"*. The merge owner added it earlier the same day.
- **The `now\(\)` grep bans the implementation it mandates.** Added in remediation round 3 to prove
  the reporting period comes from the injected clock, the bare pattern also matches `clock.now()` —
  the project's own idiom, and exactly what the same sentence requires. Four cells.
- **The colour-override proof is a no-op.** Added in round 3: a test stylesheet forcing every seat
  token to one colour, then asserting four `data-glyph` values are still distinct. **A stylesheet
  cannot change a DOM attribute**, so the clause cannot fail — and it was written to exclude
  precisely the defect it now permits.
- **Three self-matching greps were created by round 3** while it was fixing others.

## What this measures, and what it does not

Every grade is one reader's judgement on one cell, and the graders disagreed with each other on
where `VAGUE` ends and `WRONG` begins — each named its three least-confident calls. **The 91 is
therefore a considered figure, not an exact one.** What is not in doubt is the shape: the same eight
mistakes, made repeatedly, in the cells that matter most.

**Nothing here was executed.** No application code exists. Every criterion describes a test for
software that has not been written, and every defect above is a defect in a *specification of a
test*, found by reading.
